## Naming policy
- Stable IDs remain unchanged so progress and corrections are not lost.
- Display titles use source metadata where available.
- Titles marked as inferred in source extraction remain explicitly described as inferred; no new medical identity is fabricated.
- Future title changes must update this audit and add a regression test.
