# Uploaded 2026-10-03 source bundle

GitHub does not accept files over 100 MB in ordinary Git objects, so the five original archives are stored here as numbered 90 MB parts. From the repository root, run:

```bash
./scripts/assemble-uploaded-2026-10-03.sh
```

The script reconstructs the exact archive names referenced by `library/books.json`. SHA-256 values are recorded in `docs/SOURCE_CHECKSUMS_2026-10-03.json`.
